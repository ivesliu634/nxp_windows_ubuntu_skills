# NXP 工作区约定

用中文交流。Windows 保存本工作流、资料和板级工具；业务源码与构建留在 Ubuntu server。

## 执行位置与本机配置

- 需要实际路径、连接或工具位置时读取本机 [ENVIRONMENT.md](ENVIRONMENT.md)，不输出其中的凭据。
  配置模板见 [ENVIRONMENT.example.md](docs/ENVIRONMENT.example.md)。
- 本目录为 `workspace`，Windows 资源层在同级 `..\support_level`；目录可整体重命名，不写死资料包根目录名。
- Windows：RM、原理图、BSP 文档、镜像、板级知识、BCU/UUU/串口/USB 操作及完整 case。
- Ubuntu server，经 `ssh myserver`：业务源码仓库、源码搜索与修改、SDK、工具链、固定固件和构建现场。
  不在 Windows clone 业务源码或取回整棵源码、编译缓存；新源码也在 server 获取。
- 本工作流及 skills 的 Git 仓库只在 Windows 维护。server 不部署 `workspace`、`.agents`、`.github`、
  本工作流 Git 仓库或 Windows 板级资料与工具的副本、占位目录。
- [server](../server/README.md) 只保存远端工具、规则和说明的维护/部署源，不含业务源码或资源实体，
  不可在 Windows 用它替代 server 构建；远端只更新所需文件，不整树覆盖。
- Windows 使用 PowerShell 和反斜杠；Linux 路径及命令只交给 SSH 中的 Linux 解析。
  每次 SSH 是新 shell，cwd 和环境变量在同一次调用中设置。
- 所有文件按 UTF-8 读取。不增加常驻通信桥、调度服务或全局强制状态表。

## 工程判断与改动范围

- 基准优先：先建立当前环境下最小、可信、可重复的运行基准，再引入目标改动。
  参考 demo 或标准镜像失败时，先查版本、板型、构建、打包和观察链，不先改默认业务逻辑。
  基准无法建立时明确缺失条件，不把未验证状态当作基准。
- 区分直接观察、能够证明的结论、尚不能证明的部分和下一条最小证据。
  命令成功、文件存在、串口静默或某一阶段日志，都不等于整条运行链成立。
- 客户描述、历史案例和推断不是已证实根因。存在影响主要路线的合理分歧时，
  先说明依据、不确定性和最小区分实验，与用户对齐；不把笼统计划获批当作所有方向均已确认。
- 修改前查看已有改动并保留用户工作。每次只改目标必需的层和变量，已验证正常的部分保持不动；
  出现回归时与最近的可信基准比较，保留 A/B 证据。
- 用户只要讨论、查资料、改代码或提供命令时，不自行构建、取回或上板。
  已授权范围内自主推进，不为普通步骤反复询问；方向改变或超出授权时先对齐。

## 构建与板级动作

- 使用项目自身的构建方法；Agent 的真实编译统一经 server 已部署的
  `compile-tool prepare → 展示 → run` 执行。优先复用本机配置中已验证的工具链。
- `software-state` 只由构建工具生成，不手填 hash 或把失败产物标为成功。
- 接手工作区不自动复位、切 boot mode、写 EEPROM、烧写或试编译。
- 写入前确认目标板、介质、输入文件和授权范围；会改变板状态的动作前后都做 fresh probe，
  保留原始输出。历史 COM、profile 和日志不代表当前实物。

## case 与文件交接

- 新 case 的唯一主目录为 Windows `..\support_level\work\<case>`，按需使用
  `README.md`、`records/`、`logs/`、`artifacts/`、`state/`；不另建第二个 `work/` 入口。
  server 同名 case 保存源码和构建现场，实际路径见本机配置。
- 共享参考基线与任务修改、构建现场分开。构建记录、补丁和所需产物按需取回 Windows 主 case，
  不为补齐目录而复制资源。
- server 原路径与 Windows 落地路径分开记录；取回文件以两端实际大小和 SHA-256 确认对应关系。
  Windows 板级工具只使用校验后的本地文件，不直接消费远端路径。
- 产物身份和构建结论与板级观察分别记录，不能把准备好产物写成已上板成功。
- 可复用发现先整理到 `..\support_level\to_absorb`，保留来源 case，审阅后再吸收，不改写历史证据。

## 发布边界

本机配置不进入公开仓库。凭据、内部资料、业务源码、镜像、SDK、固件、case 记录
和未经许可的工具二进制不随本工作流发布。
