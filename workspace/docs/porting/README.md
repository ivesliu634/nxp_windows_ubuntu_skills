# porting

本目录说明如何将 Windows + Ubuntu server 工作区迁移到其他环境。
这里保存迁移方法和配置模板，不保存当前机器的具体配置。

## 目录内容

| 文件 | 用途 |
|---|---|
| [README.md](README.md) | 当前目录及文件用途的说明 |
| [PORTING.md](PORTING.md) | 迁移时需要准备的资源、配置、部署范围及检查方法 |
| [ENVIRONMENT.example.md](ENVIRONMENT.example.md) | 填写当前机器环境信息的模板 |

实际配置位于 [local](../../local/README.md)。

返回 [docs 说明](../README.md)。
