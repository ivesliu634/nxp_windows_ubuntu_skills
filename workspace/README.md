# workspace

本目录保存 Agent 使用的工作区约定、技能、本机配置和工程说明。

## 目录内容

| 项目 | 用途 |
|---|---|
| [README.md](README.md) | 当前目录及各项用途的说明 |
| [AGENTS.md](AGENTS.md) | 始终适用的工程约定，以及本机配置的读取要求 |
| [.agents/skills](.agents/skills/) | 由 Agent 原生机制发现和按需加载的领域技能 |
| [local](local/README.md) | 当前机器的环境信息及可选私有补充 |
| [docs](docs/README.md) | 架构、移植及相关工程说明 |

Windows 资料和板级工具位于同级 [support_level](../support_level/README.md)。
远端工具和规则的维护/部署源位于同级 [server](../server/README.md)。
