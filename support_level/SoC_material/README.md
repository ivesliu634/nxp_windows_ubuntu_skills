# RM 与硬件资料

```text
SoC_material/
├─ imx943/
│  ├─ RM/                                 芯片参考手册、勘误
│  └─ hardware/imx943evk19b1/              B1 板原理图、设计包、rework
├─ imx95/
│  ├─ RM/
│  └─ hardware/                           确认后按 19x19_lpddr5 / 15x15 / FRDM 再分
└─ imx93/
   ├─ RM/
   └─ hardware/                           确认后按 14x14 等板型再分
```

这些目录是资料放置位置；本包未附带 PDF 或设计包。

板卡多个 revision 共存时再加一层 `rev-B1/` 等目录。`imx943evk19b1` 本身已包含板卡版本，无需重复。
同一板型的 SCH / SPF / LAY 和设计压缩包放在一起，保留供应方原文件名及文档号。解包文件放同名子目录。
RM 依芯片归档；原理图依板型、封装、DDR、板卡 revision 归档，不能拿另一 EVK 的接线当当前板。

资料到位时，在相应目录附一个简短 README：资料来源、文档号与版本、适用板型，必要时加常查的电源/连接器/调试接口页号。
原理图页码要区分 PDF 页序和图纸自己的 sheet 编号。只在找到真实文件后登记。

检索路线：文件名和板型 → PDF 目录/关键词 → 对应 sheet 上网络名、器件位号、连接器针脚。软件 pinmux 与设备树再到 server 对照。
