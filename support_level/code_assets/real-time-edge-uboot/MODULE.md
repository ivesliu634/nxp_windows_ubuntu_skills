# real-time-edge-uboot

来源：[Real-Time Edge U-Boot](https://github.com/nxp-real-time-edge-sw/real-time-edge-uboot)，clone URL 为 `https://github.com/nxp-real-time-edge-sw/real-time-edge-uboot.git`。

用于软件线明确选中的 RTE bootloader。对应 ref、配置、patch 从该 release 的说明与 [meta-real-time-edge](../meta-real-time-edge/MODULE.md) 的 recipe / bbappend 查。
代码定位和分开的配置、编译命令形式见 [uboot-imx](../uboot-imx/MODULE.md)，参数要用当前 RTE 版本对应值。
原 Ubuntu 快照中各模块版本并非统一基线，不以它们的“最近版本”拼出 RTE 整套镜像。
