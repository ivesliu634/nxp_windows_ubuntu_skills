# i.MX943 EVK B1

- 原 Windows BCU profile：[板控记录](../tools/bcu/profiles/imx943evk19b1/README.md)。
- 原 Windows serial profile：[串口说明](../tools/serial-console/scripts/profiles/imx943evk19b1/README.md)、[映射](../tools/serial-console/scripts/profiles/imx943evk19b1/serial.yaml)。
- 原理图位置：`SoC_material/imx943/hardware/imx943evk19b1/`；芯片手册位置：`SoC_material/imx943/RM/`。

历史实测是板卡 B1、芯片 A0、LPDDR4；BCU 使用 `imx943evk19b1`。新实物仍需核对芯片及 DDR，板卡 B1 不等于芯片 B1。
该板历史控制前提 SW7-1 OFF；不要把 Ubuntu A0 板卡记录的拨码直接套过来。
2026-11-10 用户确认四口顺序：CM33S if00、空/BCU if01、U-Boot/Linux if02、OEI/SMFW if03。
这是同一适配器的接口顺序，不固定 COM 号；缺口不补位、不跨适配器排序。
BCU if01、a-core if02、SM if03 有历史实测；CM33S 本次未上板验证。捕获相关日志口 READY 后再 reset 可以抓早期启动日志。
原 FTDI 序列号 0C1819、COM153..156 仅为原验证记录，不用于固定绑定新电脑。
